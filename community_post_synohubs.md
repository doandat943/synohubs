## SynoHubs — The missing NAS companion app (Android + Windows, open source)

Hey everyone! 👋

I'd like to share a project I've been working on — **SynoHubs**, a free and open-source app for managing Synology NAS devices. It works on **Android** and **Windows**, with a focus on **privacy** and **zero cloud dependency**.

### Why I built this

Like many of you, I love my Synology NAS but found the official mobile apps fragmented — DS File, DS Audio, DS Video, DS Photo, etc. I wanted **one app** that gives me a clean dashboard, file management, media streaming, and admin tools, all in one place. And I wanted something that **never phones home**.

📸 **[Screenshot 1: Dashboard overview — CPU, RAM, Storage, Network]**

### What it does

**📊 Real-Time Dashboard**
- Live CPU, RAM & disk usage monitoring
- Storage pool health & volume status
- Network traffic in real-time
- Connected users & active services

📸 **[Screenshot 2: Dashboard with real NAS data]**

**📁 File Station**
- Browse, upload, download, rename, delete
- Grid & list view with sorting
- Preview images and documents
- Share files with links

📸 **[Screenshot 3: File Station showing folder structure]**

**🎬 Media Hub**
- Stream video & audio directly from your NAS
- Background audio playback with media notification controls
- Browse by folder or library
- Supports common formats (MKV, MP4, FLAC, MP3, etc.)

📸 **[Screenshot 4: Media Hub — video library or music player]**

**📦 Docker & Package Management**
- View, start, stop, restart Docker containers
- Monitor container status and resource usage
- Browse and manage installed packages
- Start/stop packages remotely

📸 **[Screenshot 5: Docker container list]**

**🖼️ Photo Browser**
- Browse Synology Photos albums
- Grid view with smooth scrolling
- Full-screen preview with zoom

**👥 User & Group Management**
- View all users and groups
- See user details and permissions

### Key highlights

| Feature | Details |
|---|---|
| 🔒 Privacy | AES-256 encryption. No cloud, no analytics, no tracking. Your data stays on YOUR network. |
| 🌐 QuickConnect | Works with Synology QuickConnect — no port forwarding needed |
| 🌍 6 Languages | English, Vietnamese, Russian, Chinese, Japanese, Korean |
| 💰 Price | **Free** and **open source** (MIT license) |
| 📱 Platforms | Android (APK) + Windows (MSI/EXE installer) |
| 🔄 Auto-update | In-app update checker — never miss a new version |

### How to connect

1. Download the app
2. Enter your NAS IP/hostname or QuickConnect ID
3. Login with your DSM credentials
4. That's it — no registration, no accounts, no cloud

📸 **[Screenshot 6: Login screen with QuickConnect option]**

### Xpenology compatible? ✅

Yes! SynoHubs works with both official **Synology DSM** and **Xpenology** installations. It connects via the standard Synology API — if your DSM is accessible, SynoHubs will work.
